Projects

PSOC 6

Runaway Alarm robot

C · FreeRTOS · PCB Design

A two-wheeled, self-balancing alarm clock on a PSoC 6 that drives off when the alarm rings and has to be caught to stop it, built with FreeRTOS tasks for balancing, object avoidance, RTC, Bluetooth, the display, and motor control. Implemented PID-based balance and steering using IMU and time-of-flight sensor data for real-time control, and designed custom IMU, EEPROM, and magnetometer boards enabling full system integration and testing. The project won the Best Capstone Project Award.

16-BIT ISA

Pipelined processor with cache hierarchy

Verilog · ModelSim

A 5-stage pipelined processor for a 16-bit ISA with branch flushing, hazard detection, and data forwarding, with 2-way set-associative instruction and data caches using LRU, write-through, and write-allocate. Developed directed testbenches in ModelSim to validate control hazards, data hazards, and cache miss-handling FSM behavior.

FPGA

Knight's Tour robot on FPGA

SystemVerilog · Quartus

An FPGA-based autonomous robot that solves the Knight's Tour on a 5×5 board. Designed a command processor state machine for movement, calibration, and tour execution with error correction from gyroscope and IR feedback, and a TourLogic block that maps the tour to hardware with 1-hot move memory. Built functional and post-synthesis testbenches, and reduced synthesized area by 12.5 percent while resolving timing and hold-time violations.

MSP432

Press Your Luck, two-player

C · FreeRTOS

A real-time, multiplayer version of the game across two microcontrollers. Implemented the core game mechanics (random active-square selection, spin tracking, Whammy detection) with interrupt-driven I/O, and developed memory-mapped I/O and UART protocols for data exchange between the two boards, coordinated with FreeRTOS tasks and semaphores.

PSOC 6 · CUSTOM PCB

Whack-a-Mole on a custom board

C · Altium Designer

An interactive hardware game built around a custom PCB. Created the schematic and a multi-layer layout in Altium Designer, assembled the board with surface-mount soldering and a reflow oven, and programmed the microcontroller to randomize mole positions, track input, and manage round timing.
